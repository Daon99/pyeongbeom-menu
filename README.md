# 카페 평범 · 모바일 웹 메뉴판

QR 스캔용 메뉴판 웹페이지.

- 주소: https://daon99.github.io/pyeongbeom-menu/
- 원본: `평범 기본 메뉴판 드라이브 업로드 본.pdf` (6페이지 인쇄용)

## 구성
- `index.html` — 메뉴판 전체 (단일 파일)
- `img/` — PDF에서 추출·최적화한 메뉴 사진 10장
- `QR/` — 인쇄용 QR 코드 및 테이블 카드

## 수정 방법
`index.html` 을 고치고 커밋·푸시하면 1~2분 뒤 사이트에 반영됩니다.
가격은 원 단위 전체 표기(예: `6,300`)로 되어 있습니다.
